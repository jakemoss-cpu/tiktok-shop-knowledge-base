# TikTok Shop Knowledge Base

Automatically maintained knowledge base distilled from Clari call transcripts.
Updated nightly via n8n ingestion pipeline.

## Structure

- `/objections` — Common objections and winning responses
- `/discovery` — Discovery call patterns and champion identification
- `/close-patterns` — Closing techniques and multi-stakeholder strategies
- `/competitive` — Competitive intel vs other agencies and in-house teams
- `/operations` — TikTok Shop operational knowledge and platform mechanics
- `/raw-calls` — Distilled summaries from individual Clari calls
